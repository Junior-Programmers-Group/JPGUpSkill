Foundations

Introduction to JavaScript & The Engine

What is JavaScript?

JavaScript is a lightweight, single-threaded, high-level, dynamically typed, and multi-paradigm interpreted (or JIT-compiled) language designed for client and server runtime environments.

Key Characteristics:

• Dynamic Typing (Variables hold types, not variables themselves)

• First-Class Functions (Functions treated as standard values)

• Prototype-based Object Orientation

The Engine Architecture (V8)

JavaScript engines (like V8 in Chrome/Node, SpiderMonkey in Firefox) convert raw JS code into machine instructions via Just-In-Time (JIT) compilation.

Parser (AST)
Ignition (Bytecode)
TurboFan (Machine Code)
History

History of JS & ECMAScript Standard

1995: The Origin

Netscape & Mocha

Created by Brendan Eich in 10 days for Netscape Navigator under the code name Mocha (later renamed LiveScript, then JavaScript to leverage Java hype).

2009: Standardisation

ES5 Epoch

ECMAScript 5 introduced `'use strict'`, JSON support, native array methods (`map`, `filter`, `reduce`), and better object getter/setters.

2015 - Modern

ES6+ (ECMAScript 2015+)

The massive modern update introducing `let`/`const`, Arrow functions, Promises, Classes, Destructuring, and Modules (`import`/`export`).

TC39 Committee: Manages ECMAScript proposals in 4 stages (Stage 0 Strawman to Stage 4 Finished).

Execution Mechanics

Variables, Hoisting & Temporal Dead Zone

var
Func Scoped
let
Block Scoped
const
Immutable Binding

Hoisting Behavior

JS engine moves variable and function declarations to the top of their containing scope during compile execution context setup.

Temporal Dead Zone (TDZ)

The region between entering scope and `let`/`const` declaration line where accessing variables causes a strict `ReferenceError`.

scope_and_tdz.js 
// Hoisting with 'var'
console.log(a); // Logs: undefined (Hoisted)
var a = 10;

// Temporal Dead Zone with 'let'
// console.log(b); // ReferenceError: Cannot access 'b' before initialization
let b = 20;

// Block Scope Isolation
if (true) {
    var leaked = "I escape block!";
    let localized = "I am trapped!";
}
console.log(leaked);    // Logs: "I escape block!"
// console.log(localized); // ReferenceError
Browser Context

The Window Object & Global Context

Root Global Object

In client-side browsers, `window` is the top-level global container object. Any global variable declared with `var` automatically attaches as a property on `window`.

window.innerWidth // Screen width
window.localStorage // Storage API
window.location.href // Current URL

Timer APIs & Execution Queues

`window` exposes non-blocking timer operations handled outside the main JavaScript thread via Web APIs.

setTimeout(fn, delay); // Macrotask Queue
setInterval(fn, period); // Repeated Timer
requestAnimationFrame(fn); // Render Loop
DOM Architecture

Understanding window vs document

window Object
  • Represents the Browser Window / Tab Container.
  • Global Scope context holder (`window.varName`).
  • Hosts BOM APIs (Browser Object Model): `fetch`, `history`, `location`, `navigator`.
document Object
  • Represents the Loaded HTML Web Page Tree Structure.
  • Child property of `window` (`window.document`).
  • Primary interface for DOM querying, node generation, and UI modification.
Hierarchy Node Flow: window → window.document → <html> → <body> → Elements
DOM Traversal

DOM Selection & Querying Methods

document.querySelector('selector')

Returns the first element matching standard CSS selector syntax or `null` if none found.

document.querySelectorAll('selector')

Returns a static NodeList of all matching elements (supports `.forEach()`).

document.getElementById('id')

Fastest targeted element lookup by raw element ID string.

dom_query_examples.js 
// Query single element
const submitBtn = document.querySelector('#submit-btn');
const activeCard = document.querySelector('.card.active');

// Query static NodeList
const navLinks = document.querySelectorAll('nav a');
navLinks.forEach((link) => {
    link.classList.add('px-3', 'py-2');
});

// Converting NodeList to Array for map/filter operations
const linkArray = Array.from(navLinks);
DOM Manipulation

Modifying Content & XSS Prevention

textContent Safe

Inserts raw plain text. Special tags like `<script>` are safely rendered as literal escaped text nodes without HTML parser execution.

innerHTML Caution

Parses and renders HTML tags. High risk of Cross-Site Scripting (XSS) attacks if supplied with unsanitized user inputs!

xss_security_demo.js 
const userInput = "<img src='x' onerror='alert(\"Hacked!\")'>";
const container = document.querySelector('#output');

// DANGEROUS: Executes inline malicious script!
// container.innerHTML = userInput;

// SAFE: Escapes tags and displays pure string content
container.textContent = userInput; 

// Class & Attribute Security
container.setAttribute('aria-label', 'Safe Output');
container.classList.toggle('highlight', true);
Dynamic UI

Dynamic Element Creation & Fragments

Core Node Generation APIs

document.createElement('div')
parent.appendChild(childNode)

DocumentFragment Optimization

A lightweight off-screen document container. Appending multiple items to a fragment before inserting into the DOM reduces costly browser layout reflows from $N$ down to $1$.

dynamic_nodes.js 
const listContainer = document.querySelector('#user-list');

// Efficient batch rendering using Fragment
const fragment = document.createDocumentFragment();

const users = ['Alice', 'Bob', 'Charlie'];

users.forEach((userName) => {
    const li = document.createElement('li');
    li.className = 'p-2 border-b border-slate-800 text-sm';
    li.textContent = userName;
    fragment.appendChild(li); // No reflow yet
});

// Single DOM mutation (1 Reflow)
listContainer.appendChild(fragment);
Events

Event Listeners vs Inline Handlers

Inline Handlers (Bad Practice)

Anti-Pattern

Tightly couples JavaScript code directly inside HTML markup attributes (`onclick="handleClick()"`). Prevents multiple event registrations and breaks separation of concerns.

addEventListener (Standard)

Recommended

Cleanly registers event handlers in external script logic (`btn.addEventListener('click', fn)`). Supports multiple handlers, capture phase tuning, and removal (`removeEventListener`).

event_listeners.js 
const button = document.querySelector('#action-btn');

function handlePrimaryClick(e) {
    console.log('Primary listener executed');
}

// Attach event listener
button.addEventListener('click', handlePrimaryClick);

// Attach secondary listener without overwriting primary
button.addEventListener('click', (e) => {
    console.log('Secondary analytics listener executed');
});
Event Object

Event Object & Essential Control Methods

e.preventDefault()

Stops default browser action (e.g., stops form submit page reloads or link navigation).

e.stopPropagation()

Prevents event from bubbling further up the DOM tree hierarchy.

e.target vs e.currentTarget

e.target: The actual element triggered.
e.currentTarget: Element hosting the active listener.

event_methods.js 
const loginForm = document.querySelector('#login-form');

loginForm.addEventListener('submit', function(event) {
    // 1. Prevent page refresh on submit
    event.preventDefault();
    
    // 2. Read input value from event target
    const emailInput = event.target.querySelector('input[type="email"]');
    console.log('Submitting email:', emailInput.value);
});
Event Architecture

Event Propagation & Delegation Pattern

3-Phase Propagation

1. Capturing Phase: Event trickles down from `Window` to target element.

2. Target Phase: Event reaches actual source target.

3. Bubbling Phase (Default): Event bubbles up from target back to `Window`.

Event Delegation Pattern

Attach a single event listener to a common parent element instead of binding separate event handlers to hundreds of individual child items.

event_delegation.js 
// Delegation on parent container
document.querySelector('#todo-list').addEventListener('click', (e) => {
    // Intercept clicks specifically on delete buttons inside any list item
    if (e.target.classList.contains('delete-btn')) {
        const itemId = e.target.dataset.id;
        console.log(`Deleting todo item #${itemId}`);
        e.target.closest('li').remove();
    }
});

Async Concepts

Asynchronous JS & Legacy AJAX

What is AJAX?

Asynchronous JavaScript And XML: Enables web clients to make background HTTP requests to server APIs without triggering a full HTML document browser reload.

Legacy: XMLHttpRequest

The legacy event-driven HTTP request interface. Requires complex event callback listeners and leads to "Callback Hell" nesting structures.

xhr_legacy_example.js 
// Verbose Legacy XMLHttpRequest API
const xhr = new XMLHttpRequest();
xhr.open('GET', 'https://api.example.com/data');
xhr.onload = function() {
    if (xhr.status === 200) {
        console.log(JSON.parse(xhr.responseText));
    }
};
xhr.send();
Modern Async

Modern Async: Fetch API & Promises

fetch(url)

Modern Promise-based Web API for executing asynchronous network requests cleanly.

async / await

Syntactic sugar built over Promises allowing asynchronous asynchronous workflows to be written in a synchronous-like clean code style.

modern_fetch_async.js 
// Modern Clean Async Request with error boundary
async function fetchStudentProfile(studentId) {
    try {
        const res = await fetch(`https://api.example.com/students/${studentId}`);
        if (!res.ok) throw new Error(`HTTP error! status: ${res.status}`);
        
        const student = await res.json();
        console.log('Student loaded:', student.name);
    } catch (err) {
        console.error('Fetch error:', err.message);
    }
}
Wrap-Up

Best Practices, 5-Min Challenge & Q&A

Best Practices Checklist

  • Always prefer `const` > `let` over legacy `var`.
  • Avoid direct `innerHTML` with raw user inputs to prevent XSS.
  • Leverage Event Delegation for lists and dynamically created elements.
  • Always wrap asynchronous `await` calls in `try / catch` blocks.

5-Min Hands-on Challenge
